Privacy policy – ONEAQ Gmail MCP

Last updated: 30 October 2026

Who we are

ONEAQ Gmail MCP is an internal tool of ONEAQ Holding B.V., Grote Kerkstraat 46, 4941 DP Raamsdonksveer, The Netherlands.

What data the app accesses

The app requests the Google scope https://www.googleapis.com/auth/gmail.readonly for the Gmail account of ONEAQ Holding B.V. only. It reads message metadata, message content and attachments in order to find, read and store the company's own invoices and bank statements.

How data is used and stored

  • The app runs locally on the company's own computer. There is no server operated by the app.
  • Attachments the user chooses to save are stored in the company's own bookkeeping folder on that computer.
  • The OAuth access token is stored locally on that computer and is never shared.
  • The app cannot send, modify or delete email.

Sharing

Data obtained through Google APIs is not sold, not shared with third parties and not used for advertising. ONEAQ Gmail MCP's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
